Introducción

La tecnología y la automatización se han convertido en herramientas que puedenn resolver problemas de la vida cotidiana y poder mejorar estos procesos al hacerlos más faciles y efectivos. En el IRTRA Petapa, donde hay atracciones destinadas para personas de distintas edades y características, es necesario poder contar con tecnología que ayude a verificar las condiciones para una utilizacion segura. Entre estas condiciones, la altura es una de las principales al establecer limites específicos para garantizar la seguridad del usuario. A partir de esta necesidad, el proyecto propone el diseño de un sistema automatizado que pueda medir la altura de los usuarios mediante un sensor ultrasónico; este sistema recible la informacion proporcionada por el sensor, procesa y clasifica los rangos de altura para saber a cuales atracciones es seguro que ingresen. El desarrollo de este prototipo permite aplicar conocimienos relacionados con la autonatización, los sensores y la programacion.

Conclusión

• El desarrollo del sistema automatizado de medición de altura demuestra cómo diferentes componentes electrónicos pueden integrarse para resolver una problemática relacionada con el control de acceso a atracciones. Mediante el sensor ultrasónico HC-SR04 es posible obtener una medición de distancia que posteriormente es procesada por un Arduino Uno R3. • La programación permite establecer diferentes condiciones y asociar cada una con una respuesta específica. De esta manera, los LEDs proporcionan información visual y el buzzer complementa la indicación mediante una señal sonora. • El proyecto también permite aplicar conceptos de sensores, sistemas de entrada y salida, programación en C++, estructuras condicionales y control electrónico. Asimismo, su desarrollo se relaciona con el ODS 9 debido a la incorporación de tecnología e innovación para desarrollar una solución automatizada. • Finalmente, el prototipo constituye una demostración de cómo la automatización puede utilizarse para apoyar procesos de verificación en espacios recreativos. Sin embargo, para una implementación real sería necesario realizar pruebas de precisión, calibración y validación bajo las condiciones específicas de cada atracción.
